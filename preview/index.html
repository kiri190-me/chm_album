미리보기에서 해볼 것

  • 하단 사진 / 동영상 / 앨범 탭 전환
  • 정렬 버튼 → 촬영 날짜 ↔ 기기에 저장된 날짜
  • 항목을 길게 눌러 여러 개 선택 → 공유
  • 사진 보기에서 두 번 클릭·휠·핀치로 확대, 끌어서 이동
  • 사진 보기에서 편집: 자르기, 기울기, 90° 회전, 반전, 크기
  • 동영상 보기에서 편집: 노란 손잡이로 구간 자르기
  • Ctrl + 휠 또는 핀치로 열 개수 변경

사진과 동영상은 예시로 만든 이미지입니다. 편집하고 저장하면 원본은 그대로 두고 같은 폴더에 사본이 생깁니다. 미리보기의 공유는 실제로 전송되지 않습니다.
